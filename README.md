# akandukoori123-bit.github.io

Personal website for **Aditya Kandukoori**: AI research, machine learning,
engineering, and STEM teaching.

Built with the [Chirpy][chirpy] Jekyll theme and deployed to GitHub Pages via
GitHub Actions. Live at **https://akandukoori123-bit.github.io**.

## Editing

- Pages (About / Resume / Hobbies) live in `_tabs/`.
- Posts on the home feed live in `_posts/` (`YYYY-MM-DD-title.md`).
- Site settings (title, tagline, avatar, social links) are in `_config.yml`.
- The resume PDF is at `assets/files/resume.pdf`. Replace that file to update it.
- To swap the avatar or hero image, replace `assets/img/avatar.png` and
  `assets/img/home-intro.png`.

Every push to `main` rebuilds and redeploys the site automatically. Note: the
repo must stay public, since GitHub Pages is disabled on private repos for free
accounts.

[chirpy]: https://github.com/cotes2020/jekyll-theme-chirpy/
